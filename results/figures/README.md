# 그림 파일명 규칙

```
<문서절>_<내용>.png
```

- **`<문서절>`** — 이 그림이 실리는 문서의 절 번호. 소문자, 마침표 대신 `_`.
  예: Q4 문서의 D-1 절 → `q4_d1`
- **`<내용>`** — 무엇을 보여주는지. 소문자 영어 + `_`. 파일명만 보고 내용이 짐작돼야 한다.
- 확장자는 `.png`, 300 dpi.

문서 절 번호를 앞에 두는 이유는 그림이 늘어날 때 **문서 순서대로 정렬**되고,
절이 사라지면 어느 그림이 고아가 됐는지 바로 보이기 때문이다.
어느 문서에도 안 실리는 탐색용 그림은 여기 두지 말고 노트북 안에 남긴다.

## 규칙

1. **그림은 스크립트가 만든다.** 대화형 세션에서 그린 것을 그대로 커밋하지 않는다.
   스크립트가 없으면 재현도, 데이터가 갱신됐을 때 갱신도 안 된다.
2. **수치를 그림에 하드코딩하지 않는다.** `plot_q4_d1.py` 가 n=1,140 을 raw 에서 직접 세듯,
   표에 적힌 값과 그림의 값이 어긋날 수 없게 만든다.
3. **문서에서는 상대 경로로 건다.** 앱 URL(`127.0.0.1:8000/...`)은 저장소를 clone 한
   사람에게는 열리지 않는다.
4. **한글 라벨을 쓰면 폰트를 등록한다.** `plot_q4_d1.py` 의 `use_korean_font()` 참고.
   등록하지 않으면 모든 한글이 두부(□)로 나온다.
