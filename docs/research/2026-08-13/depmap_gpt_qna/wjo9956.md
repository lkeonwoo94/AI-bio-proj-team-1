### A-1. 프로젝트 개요

이 프로젝트에서는 암세포주의 분자 정보를 입력으로 사용하여 다음 두 가지를 동시에 예측한다.

1. 특정 약물에 대한 암세포주의 반응
2. 특정 유전자에 대한 암세포주의 CRISPR 의존성

기본 모델 구조는 다음과 같다.

```
유전자 발현 + 돌연변이 + Copy number + 암종 정보
                         ↓
                    공통 신경망
                         ↓
          PRISM 약물 반응 + CRISPR Gene Effect
```

가장 현실적인 첫 번째 모델은 다음 조합이다.

> 유전자 발현 → PRISM Secondary AUC + CRISPR Gene Effect 동시 예측

현재 정규 릴리스 데이터는 DepMap Public 26Q1이며, 약물 반응은 별도의 PRISM Repurposing 데이터로 제공된다. 릴리스가 달라도 ModelID(ACH-xxxxxx)를 기준으로 연결할 수 있다.

#### A-2-3. 유전자 발현 데이터

**권장 파일:** `OmicsExpressionProteinCodingGenesTPMLogp1.csv`

**경로:** Downloads → Current Release → Expression

Custom Downloads에서는 다음 항목에 해당한다.

**구조**

- 열: 단백질 코딩 유전자

이 데이터가 신경망의 주 입력값 X가 된다.

**X_expression**

- 행: 암세포주
- 열: 발현 유전자
- 값: log2(TPM + 1)

처음에는 약 2만 개의 전체 유전자를 모두 사용하지 않고 다음 방식으로 줄이는 것이 좋다.

- 분산이 큰 유전자 1,000~3,000개
- 암 관련 유전자 및 알려진 driver gene
- 약물 표적 유전자
- pathway 단위 요약값
- Autoencoder로 축소한 잠재변수

**주의:** 특징 선택은 반드시 학습 데이터 안에서만 수행한다. 전체 데이터에서 반응과 관련된 유전자를 먼저 고른 후 train/test를 나누면 데이터 누수가 발생한다.

#### A-2-4. CRISPR Gene Effect

**권장 파일:** `CRISPRGeneEffect.csv`

**경로:** Downloads → Current Release → CRISPR Screen → CRISPRGeneEffect.csv

**구조**

- 행: ModelID
- 열: 유전자
- 값: Chronos로 계산한 Gene Effect

**일반적인 해석**

- 0 근처: 유전자 제거의 영향이 작음
- 음수: 유전자 제거 후 세포 성장 또는 생존 감소
- 더 작은 음수: 해당 유전자에 더 강하게 의존

이 파일은 모델 수준에서 통합되고 copy-number effect와 스크린 품질 등이 보정된 데이터이므로 첫 프로젝트의 연속형 예측값으로 적합하다.

**Y_crispr**

- 행: 암세포주
- 열: 예측할 dependency 유전자
- 값: CRISPR Gene Effect

#### A-2-5. CRISPRGeneDependency.csv

선택적으로 함께 받는 것을 권장한다.

**차이**

- `CRISPRGeneEffect.csv`: 유전자 제거 효과의 연속적인 크기
- `CRISPRGeneDependency.csv`: 해당 유전자가 dependency일 확률

주 출력값은 `CRISPRGeneEffect.csv`를 권장한다. `CRISPRGeneDependency.csv`는 다음 용도로 사용할 수 있다.

- dependent/non-dependent 분류
- 출력 유전자 후보 선정
- Gene Effect 예측 결과의 보조 검증

#### A-2-6. PRISM 약물 반응 데이터

**권장 항목:** PRISM Repurposing Secondary (AUC)

Custom Downloads에서 다음 항목을 선택한다.

- PRISM Repurposing Secondary (AUC)
- 또는 Drug sensitivity AUC (PRISM Repurposing Secondary Screen)

**Secondary AUC를 추천하는 이유**

- 여러 농도의 용량-반응 데이터에 기반함
- 단일 농도 viability보다 안정적임
- 연속값 회귀 문제로 사용하기 편함
- 대체로 0~1 범위로 정규화됨

**일반적인 해석**

- 낮은 AUC: 약물에 민감
- 높은 AUC: 약물에 저항성

정확한 값의 정의와 방향은 다운로드한 데이터의 README에서 다시 확인한다.

**Y_drug**

- 행: 암세포주
- 열: 약물
- 값: PRISM AUC

**대안:** PRISM Repurposing Primary (Viability)

Primary 데이터는 더 많은 약물을 포함하지만 단일 농도 중심이고 결측값이 많을 수 있다. 처음에는 Secondary AUC로 모델을 만든 다음 Primary 데이터로 확장하는 것이 좋다.

### A-6. 데이터 결합 방법

Expression, CRISPR, PRISM, Model metadata에 공통으로 존재하는 ModelID만 사용한다.

개념적 Python 코드:

```python
common_ids = (
    set(expression.index)
    & set(crispr.index)
    & set(prism.index)
    & set(model["ModelID"])
)

common_ids = sorted(common_ids)

X_expression = expression.loc[common_ids]
Y_drug = prism.loc[common_ids]
Y_crispr = crispr.loc[common_ids]
```

**최종 데이터 구조**

| 테이블 | 행 | 열 |
|---|---|---|
| `X_expression` | 공통 ModelID | 유전자 발현 |
| `Y_drug` | 동일한 공통 ModelID | 선택한 약물 |
| `Y_crispr` | 동일한 공통 ModelID | 선택한 dependency 유전자 |
| Metadata | 동일한 ModelID | 암종, 세부 아형 등 |

공통 ID를 선택한 뒤 모든 테이블의 행 순서도 명시적으로 동일하게 맞춘다.

### A-7. 권장 프로젝트 범위

처음부터 모든 약물과 모든 유전자를 예측하면 출력 차원이 지나치게 커지고 과적합 및 결측치 문제가 심해진다.

**첫 번째 구현 권장 범위**

- 세포주: PRISM, CRISPR, expression에 공통으로 존재하는 모델
- 입력 유전자: 분산이 큰 발현 유전자 1,000~2,000개
- 약물 출력: 관측 표본이 충분한 약물 50~100개
- CRISPR 출력: 선택적 dependency 유전자 100~300개
- 암종: Pan-cancer 또는 표본이 많은 3~5개 암종

**CRISPR 출력 유전자 선정 기준**

- 결측률이 낮음
- 세포주 간 Gene Effect 분산이 충분함
- 일부 세포주에서 강한 dependency를 보임
- 약물 표적과 연결 가능함
- 공통 essential에만 해당하지 않음

### A-8. 권장 1차 모델 구조

**입력**

- Expression: 1,000~2,000개
- Mutation: 주요 유전자 50~200개
- Copy number: 주요 유전자 50~200개
- 암종 one-hot encoding

**구조**

```
유전자 발현 + 돌연변이 + Copy number + 암종
                         ↓
                    공통 Encoder
                         ↓
                    공통 잠재표현
                  ↙               ↘
          Drug response head     CRISPR head
          PRISM AUC 50~100개     Gene Effect 100~300개
```

**권장 손실함수**

```
Total loss
= alpha × masked MSE(PRISM AUC)
+ beta  × masked MSE(CRISPR Gene Effect)
```

PRISM에는 결측값이 있으므로 관측된 값에만 손실을 계산하는 masked MSE가 필요하다.

### A-9. 분석 시 중요한 주의사항

#### A-9-1. 출력 방향 확인

일반적으로:

- PRISM AUC가 낮을수록 약물 민감성이 큼
- CRISPR Gene Effect가 낮을수록 유전자 의존성이 큼

해석 편의를 위해 다음처럼 변환할 수 있다.

- Drug sensitivity score = 1 − AUC
- Dependency strength = −GeneEffect

변환한 경우 보고서와 코드에 반드시 기록한다.

#### A-9-2. 약물과 표적 유전자를 일대일로 가정하지 않기

한 약물은 여러 표적을 가질 수 있고 off-target 효과도 존재한다. 약물은 단백질 기능을 부분적으로 억제하는 반면 CRISPR는 유전자 기능을 강하게 제거하므로 두 효과가 동일하지 않다.

약물 반응과 CRISPR Gene Effect는 별개의 출력으로 학습하고, 모델 학습 후 두 결과의 관계를 분석하는 것이 안전하다.

#### A-9-3. 데이터 분할

랜덤 분할만 사용하면 같은 암종의 유사한 세포주가 train과 test에 나뉘어 성능이 과대평가될 수 있다.

**권장 평가**

- 암종 비율을 유지한 stratified split
- lineage를 고려한 group split
- Leave-one-lineage-out
- 약물별 Pearson/Spearman correlation
- CRISPR 유전자별 Pearson/Spearman correlation
- 전체 RMSE 및 MAE

#### A-9-4. 결측값 처리

- PRISM AUC의 결측값을 무조건 평균으로 채우지 않음
- 관측된 출력에 대해서만 loss를 계산
- 약물별 최소 관측 세포주 수 기준 설정
- 세포주별 및 약물별 결측률 보고
