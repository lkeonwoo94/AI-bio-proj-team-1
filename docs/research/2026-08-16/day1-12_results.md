DepMap Public 26Q1 / 코호트 1,631 세포주 / feature 20,132
(hotspot 554 + damaging 19,578) / lineage 32종

* `IsDefaultEntryForModel == "Yes"` 로 세포주당 대표 프로파일만 사용
  → 3,044 행 → 1,968 세포주
* WGD/CIN/LoHFraction 이 함께 결측인 337 행 제외 → **1,631 세포주**
* mutation 값은 개수이지만 존재 여부만 사용 (`> 0`)

## 2. 표현형 간 상관 (RQ4 배경)

Spearman 상관이 낮지 않다.

| | WGD | CIN | LOH |
| --- | --- | --- | --- |
| WGD | 1.000 | 0.773 | 0.619 |
| CIN | 0.773 | 1.000 | 0.723 |

세 표현형을 별도로 예측한다는 README §2 의 설계는 유지하되,
성능이 서로 비슷하게 나오는 것이 우연이 아닐 수 있음을 감안해야 한다.

## 3. 모델 비교 (Day 10, random 5×5 nested CV)

ROC-AUC 평균:

| 모델 | WGD | CIN | LOH |
| --- | ---: | ---: | ---: |
| Logistic | 0.723 | 0.672 | 0.683 |
| Elastic Net | 0.749 | 0.681 | 0.711 |
| **Random Forest** | **0.765** | **0.734** | **0.730** |
| XGBoost | 0.757 | 0.729 | 0.728 |
| Multi-task ANN | 0.704 | 0.671 | 0.667 |

### 읽을 점

* **RQ1–RQ3 은 "제한적으로 가능"** 이다. 세 표현형 모두 0.67–0.77 구간으로
  무작위(0.5)보다 확실히 높지만 임상적으로 쓸 수준은 아니다.
* **WGD 가 가장 잘 예측된다.** PR-AUC 0.84 로 보이지만 WGD+ 가 65% 인
  다수 클래스라 기저선 자체가 높다. PR-AUC 를 표현형 간 비교에 쓰면 안 된다.
* **비선형 모델이 일관되게 앞선다** (RF/XGB > 선형). 변이 간 interaction 이
  일부 존재한다는 뜻이다.
* **Multi-task ANN 이 가장 낮다.** RQ4 에 대해서는 부정적 결과다 —
  표현형 간 상관이 높음에도 공유 표현이 개별 모델을 이기지 못했다.
  샘플 1,631 개에 feature 2,000 개 규모에서 MLP 가 불리한 탓일 수 있으므로
  "공유 신호가 없다" 가 아니라 "이 설정에서는 이득이 없다" 로 해석한다.

## 4. 반복 feature selection (Day 11, Elastic Net)

전 fold(5/5)에서 선택된 유전자:

* **세 표현형 공통**: `TP53`(damaging), `ID3`, `BRAF`(hotspot), `CREBBP`
* **WGD 특이**: `TERT`(hotspot), `NF2`, `CCND3`, `LRP1B`, `TGFBR2`
* **CIN 특이**: `RB1`, `PIK3CA`(hotspot), `SLFN11`
* **LOH 특이**: `NF2`, `PITX1`, `MUC19`, `ABCB5`

`TP53` 은 세 표현형 모두에서 평균 순위 1.0 (rank_std 0.0) 이다.
유전체 불안정성의 대표 유전자라는 점에서 방향성 검증(sanity check)이 된다.

## 5. 최소 패널 (Day 12, Elastic Net)

전체 feature 대비 ROC-AUC 유지율:

| 패널 | WGD | CIN | LOH |
| --- | ---: | ---: | ---: |
| 5개 | 0.709 (95%) | 0.655 (96%) | 0.666 (94%) |
| 10개 | 0.727 (97%) | 0.674 (99%) | 0.669 (94%) |
| 20개 | 0.730 (97%) | 0.667 (98%) | 0.666 (94%) |
| 50개 | 0.707 (94%) | 0.654 (96%) | 0.657 (92%) |
| 전체 | 0.749 | 0.681 | 0.711 |

### 두 가지 주의

**성능 곡선이 단조롭지 않다.** 50개가 10–20개보다 낮다. 패널 크기가
바뀌면 inner CV 가 고르는 규제 강도도 달라지기 때문으로 보이며,
"50개가 10개보다 나쁘다" 로 읽을 것이 아니라 **10개 이후로는 평평하다**
로 읽는 것이 맞다.

**패널 구성이 불안정하다.** fold 간 Jaccard 유사도:

| | 5개 | 10개 | 20개 | 50개 |
| --- | ---: | ---: | ---: | ---: |
| WGD | 0.563 | 0.410 | 0.371 | 0.277 |
| CIN | 0.440 | 0.332 | 0.251 | 0.229 |
| LOH | 0.476 | 0.295 | 0.201 | 0.238 |

즉 **성능은 유지되지만 어떤 유전자로 유지되는지는 fold 마다 다르다.**
5개 패널에서도 절반 정도만 겹친다. README §18 이 요구한 '안정성' 기준을
충족한다고 보기 어렵다.

20개 패널에서 전 fold 공통으로 뽑힌 유전자는
WGD 7개 / CIN 4개 / LOH 3개뿐이다.

### 잠정 해석

성능만 보면 "10개로 충분" 이지만, 안정성을 함께 보면
**소수의 핵심 유전자(TP53, ID3, BRAF, TERT, NF2, RB1) + 나머지는 교체 가능**
한 구조에 가깝다. README §25 의 "예측 성능 높음 + 작은 패널 성능 유지" 와
"신호가 여러 유전자에 분산" 이 섞인 중간 형태다.
