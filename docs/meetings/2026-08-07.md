## 논의 사항

### 1. 주제 후보: 알츠하이머 vs 항암

- 둘 다 요즘 활발히 연구되는 "핫한" 주제. 둘을 섞을 가능성도 검토.

#### a. **알츠하이머(ADNI)로 할 수 있는 것**
- 치매 진행 예측 모델
- MRI 기반 뇌 위축 분석
- 유전자 영향 분석
- 인지검사 변화 예측
- PET-MRI 비교
- CSF 바이오마커 분석
- 치매 환자 군집화
- 치매 진행 속도 예측
- XAI로 치매 발병 확률을 의사에게 설명
- 멀티모달 통합(MRI + CSF + PET 등)

**활용 가능 데이터(ADNI)**: 부검 병리 결과, MRI/PET, 임상 진단, 뇌 부피, 신경심리 검사, 혈액 데이터, 단백체 데이터

#### b. **항암으로 할 수 있는 것**
- 항암 타겟 유전자 발굴
- 특정 암의 essential gene 탐색
- 유전자 발현과 약물 반응 관계 분석
- 돌연변이에 따른 약물 반응 분석
- 암세포 군집화
- 약물 반응 예측 모델
- 바이오마커 발굴
- 약물 재창출(drug repurposing) — 기존 약물의 새로운 적응증 탐색
- 암 종류별 유전자 의존성 시각화(heatmap, dependency map)
- 유전자 억제 시 암세포 반응 관찰(CRISPR gene effect)

**필요 데이터(항암)**: DNA, RNA, Protein 등 다양하며 나눠서 진행 가능. 후성유전(epigenetic), 전이(metastatic) 관련 주제도 있음.

- 암은 제약바이오 전반에서 다뤄지는 만큼 활용 범위가 넓고, 알츠하이머도 최근 폭넓게 연구되는 중 → 둘 다 확장성은 있다고 판단.

### 2. `항암 방향 좁히기`

- 암 / 약물 / 유전자, 이 3개 축 중 2개의 관계를 보는 게 현실적이라는 의견.
- 후보로 논의된 세부 방향:
  - 기존 약물의 새로운 적응증 탐색(drug repurposing) — 최근 관심 높음, DepMap에 관련 데이터 있음
  - CRISPR gene effect 기반 특정 암의 essential gene 찾기
  - 유전자 발현과 약물 반응의 상관관계 탐색 (RNA-seq + correlation 분석)
    - 목표 : "발현량이 높을수록 잘 듣는 약" 탐색
  - 암을 특징짓는 유전자 찾기 
    - → 기존 약물이 폐암에 있는 ...-> 유방암에도 효과가 있을 것 같다. 이런 약물 새로운 적응증을 찾을 것인지
  - 공통 돌연변이 탐색
  - 암세포 특성별 군집화
  - 약물 반응 예측 모델
    - 이 약물을 유전자에 썼을 때 어떻게 결과가 나올지
  - 유전자 조합 억제 시 암세포 반응(바이오마커 탐색)
  - 암종별 유전자 의존성 시각화(heatmap/dependency map)
- 암은 돌연변이 종류가 매우 많아 무언가 새로 발굴하면 그 자체로 논문감이 된다는 코멘트.

### 3. 최신 트렌드 및 팀원 관심사

- 최근 뜨는 분야: 단백질 구조 예측, 항체 설계 예측, 약물 재창출 예측 모델.
- 기존 약물은 대부분 합성 화합물(synthetic drug).
- "약물 반응 예측"은 수업 실습(약물 이름만 바꿔서 진행한 데이터 분석)과 유사한 접근으로 가능.
- 팀원 관심사:
  - 현희님 — 바이오 의약품(항체 계열) 약물
  - 수현님 — CRISPR 활용 연구
  - 주영님 — 항체(타겟 지정 후 항체 제작) 관련 경험 있음
  - 건우님 — 다 좋음
- 최근 바이오 의약품은 항체 기반이 많고, 특히 ADC(Antibody-Drug Conjugate)가 주목받는 중 — 항체가 특정 단백질 발현 부위를 인식해 약물을 전달하는 방식.
- 단백질이 어떻게 발현되는지 예측하는 것 자체가 아직 난제로 남아 있음 → 접근 난이도 고려 필요. 무조건 어려운 주제보다 실현 가능한 범위를 택하자는 데 공감.

### 4. DepMap 활용 아이디어로 수렴

- CRISPR 유전자 의존성 예측 쪽으로 방향을 좁힘. [DepMap](https://depmap.org/portal/data_page/?tab=overview)에 CRISPR NGS/screen 데이터 존재.
- 민감도(sensitivity), 영향(effect)을 정량화하는 게 핵심 — 실제 데이터를 받아봐야 세부 설계 가능.
- 큰 그림:
  1. 1단계: 유전자 발현 기반 CRISPR 의존성 예측
  2. 2단계: 1단계 + 약물 반응까지 확장

**아이디어 1 — 유전자 발현으로 CRISPR 의존성 예측**
- 입력: 유전자 발현, 돌연변이, Copy number, 암종
- 출력: CRISPR Gene Effect
- 모델: Elastic Net, XGBoost, MLP, Multi-task 신경망
- 목표: 암세포의 취약 유전자 탐색, 암종별 치료 표적 후보 발굴, 치료 반응 바이오마커 탐색
- 장점: 구현 난이도가 낮고 생물학적 해석이 용이함

**아이디어 2 — 약물 반응 + CRISPR 의존성 동시 학습(Multi-task)**
- 입력: 유전자 발현, 돌연변이, Copy number, 암종
- 출력: PRISM 약물 반응, CRISPR Gene Effect (하나의 신경망에서 동시 예측)
- 구조: 암세포 분자 정보 → 공통 신경망 → (약물 반응 예측 / 유전자 의존성 예측) 두 갈래 출력
- 목표: 약물 반응 예측 + 효과 기전(타겟) 추론, 기존 약물의 새 암종 적용 가능성 탐색, 암종별 취약 유전자·바이오마커 발굴
- 장점: 딥러닝 적용 근거가 명확하고 약물 재창출로 바로 연결 가능
- 단점: 데이터 연결과 모델 설계 복잡도 높음


## 결정 사항

- 주제는 **항암(DepMap 기반)** 쪽으로 방향을 잡는다.
- 진행 순서는 **아이디어 1(유전자 발현 → CRISPR 의존성 예측)을 먼저 구현하고, 이후 아이디어 2(+ 약물 반응 Multi-task)로 확장**하는 방식으로 한다.
