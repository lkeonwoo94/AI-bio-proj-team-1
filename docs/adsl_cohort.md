# ADSL 코호트 상세

근거 데이터: `ADNIMERGE2/data/ADSL.rda` (ATRI Biostatistics 배포 v0.1.1, tbl_df 5,146 × 55).
자료 위치·접근 방법은 [study_info.md](study_info.md)를 참고하세요.

## 결측치와 결측치 41% — 미등록자

`ADSL` 5,146행 중 `DX`, `EDUC`, `CDRSB`, `MMSCORE` 가 일제히 약 41% 비어 있습니다.
`ENRLFL`(등록 여부, `man/ADSL.Rd`상 "Enrolled Population Flag")와 교차하면 원인이 드러납니다.

| | `DX` 있음 | `DX` 결측 |
|---|---:|---:|
| `ENRLFL = Y` (등록) | 3,030 | 2 |
| `ENRLFL` 결측 (미등록) | 0 | 2,114 |


> **결측은 전부 미등록자입니다.** 
> >**분석 코호트는 `ENRLFL == "Y"` 로 걸러야 합니다.** 이 필터를 적용하면 결측률이 정상으로 돌아옵니다.

| 변수 | 전체 5,146명 | 등록자 3,032명 |
|---|---:|---:|
| `DX` | 41.1% 결측 | **0.1%** |
| `EDUC` | 41.1% | **0.1%** |
| `CDRSB` | 41.1% | **0.1%** |
| `MMSCORE` | 41.2% | **0.2%** |
| `APOE` | 41.5% | **12.4%** |
| `AMYSTAT` | 68.7% | **46.9%** |

`APOE` 12.4%와 `AMYSTAT` 46.9%는 필터 후에도 남는 진짜 결측입니다.
유전형 검사와 amyloid PET을 모든 참가자가 받지는 않았기 때문입니다.

`BMI` 는 등록 여부와 무관하게 99.2%가 비어 있어(n=39) 사실상 쓸 수 없습니다.

`ADSL`의 파생 기저 변수(`EDUC`, `MMSCORE`, `CDRSB` 등)는 등록 집단에만 채워지는 값이며,
미등록 상태 자체가 곧 "평가 기록 없음"을 뜻하지는 않습니다. 실제로 미등록 2,114명 중
758명은 `DXSUM`에 스크리닝 시점 진단 기록이 남아 있습니다 (CN 373 · MCI 285 · 치매 92,
방문 수 중앙값 1회·최대 2회, 전원 ADNI2/3/4 소속 — ADNI2 266 · ADNI3 270 · ADNI4 222).
분석 코호트 정의(`ENRLFL == "Y"` 3,032명) 자체는 달라지지 않지만, 스크리닝 탈락자를
다루는 연구(예: 등록 선택 편향 분석)라면 `ADSL` 단독이 아니라 `DXSUM` 등 원본 계열
테이블을 함께 봐야 합니다.
